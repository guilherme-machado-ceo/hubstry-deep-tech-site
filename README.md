## 🇧🇷 Português

**Hubstry Deep Tech** é um *operating deep tech venture builder* brasileiro com foco na demarcação teórica e prática entre Direito, Tecnologia e Capital. Este repositório contém o código-fonte da landing page oficial da organização.

### 🔬 O que o projeto aborda:
- **ILMO (Segurança Pós-Quântica):** Avaliação do risco de colapso de criptografia e mapeamento de vulnerabilidade sob o modelo *"Harvest Now, Decrypt Later"*.
- **HGCF (Governança de IA):** Framework proprietário e compliance normativo alinhado diretamente aos controles e cláusulas da ISO/IEC 42001:2023.
- **CPG (Inteligência Regulatória):** Arquitetura de demarcação de domínios corporativos e atlas jurídico-regulatório (Lex-IO-Graph).
- **Logística Quântica:** Roteamento de frotas (QUBO-VRP) que simula pesadas vantagens competitivas e drástica redução nas emissões de CO₂.
- **GuruDev™:** Linguagem primária e ontológica em desenvolvimento.

### 💻 Stack Tecnológico
O projeto foi construído para alta performance estática:
- `Vite` (Bundler extremamente rápido)
- `React` (Biblioteca principal)
- `TypeScript` (Tipagem forte para escalabilidade)
- `Tailwind CSS` (Estilização via classes utilitárias)

### 🚀 Como rodar localmente

Instale as dependências padrão:
```bash
npm install
```

Inicie o servidor de desenvolvimento local:
```bash
npm run dev
```

### ☁️ Como realizar o Deploy (Produção)
A implantação ocorre de modo totalmente automatizado na branch \`gh-pages\` ignorando o uso de frameworks geradores internos da plataforma (via flag `.nojekyll` e `--dotfiles`):

```bash
npm run deploy
```

## 🇺🇸 English

**Hubstry Deep Tech** is a Brazilian operating deep tech venture builder focused on the theoretical and practical demarcation between Law, Technology, and Capital. This repository holds the source code for the organization's official landing page.

### 🔬 Features Covered:
- **ILMO (Post-Quantum Security):** Cryptographic risk assessment and vulnerability mapping under the *"Harvest Now, Decrypt Later"* quantum threat model.
- **HGCF (AI Governance):** Proprietary framework and normative compliance aligned directly with ISO/IEC 42001:2023 controls and clauses.
- **CPG (Regulatory Intelligence):** Corporate domain demarcation architecture and legal-regulatory atlas (Lex-IO-Graph).
- **Quantum Logistics:** Fleet routing (QUBO-VRP) simulating heavy competitive advantages and drastic reductions in CO₂ emissions.
- **GuruDev™:** Primary ontological language currently in development.

### 💻 Tech Stack
The project was built for high static performance:
- `Vite` (Lightning-fast bundler)
- `React` (Core UI library)
- `TypeScript` (Strong typing for scalability)
- `Tailwind CSS` (Utility-first styling approach)

### 🚀 Running Locally

Install the standard dependencies:
```bash
npm install
```

Start the local development server:
```bash
npm run dev
```

### ☁️ Deployment (Production)
Deployment happens fully automated out of the box directly onto the \`gh-pages\` branch by bypassing GitHub's internal static site generator processes (via the `.nojekyll` flag embedded with `--dotfiles` parameter):

```bash
npm run deploy
```
